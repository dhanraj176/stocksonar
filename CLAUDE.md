## Project status

StockSonar is an early-stage Next.js app: the repo is still the `create-next-app` scaffold (`app/layout.tsx`, `app/page.tsx`) plus tooling. The product spec lives in `docs/PRD.md` — read it before building features. Summary:

- An AI research copilot for retail investors (US stocks) and investment clubs. Users import holdings (screenshot or CSV), record *why* they own each stock, and get cited bull/bear reports from Claude agents. A devil's-advocate agent challenges every report. Alerts fire when news weakens the user's stated thesis. A morning brief covers what changed overnight. Club members propose trades and vote on them.
- Data for v1 comes only from free sources: SEC EDGAR plus one free market-data/news API.
- Hard product rules:
  - It is research, not advice. The app never tells users to buy or sell.
  - Every claim in a report must cite a source the app actually fetched.
  - Club votes are recorded only. The app never executes trades or holds money.

## Commands

```bash
npm run dev          # next dev (Turbopack) on http://localhost:3000
npm run build        # production build
npm run lint         # eslint (flat config: next core-web-vitals + typescript)
npm test             # vitest run (passes even with no test files)
npx vitest run path/to/file.test.ts   # single test file
npx vitest run -t "test name"         # single test by name
npx tsc --noEmit     # typecheck (there is no script for it)
```

## Stack and config notes

- **Next.js 16.4 / React 19.3, App Router only** (`app/`). APIs differ from older Next.js, so check `node_modules/next/dist/docs/01-app/` before writing framework code (see AGENTS.md above).
- **`cacheComponents: true`** is enabled in `next.config.ts`. This changes the caching and rendering model: dynamic data must sit behind `<Suspense>` or use `"use cache"`. See `01-getting-started/08-caching.md` and `02-guides/migrating-to-cache-components.md` in the bundled docs. Don't use pre-Cache-Components patterns such as `export const dynamic` or `revalidate` segment config without checking the docs first.
- **`partialPrefetching: true`** is also enabled. See `02-guides/adopting-partial-prefetching.md`.
- **`experimental.agentFeedback: true`**: `next dev` rewrites the block in `AGENTS.md`. Commit that file as-is instead of reverting it.
- **Tailwind CSS v4** loads through the `@tailwindcss/turbopack` loader configured in `next.config.ts` (there is no PostCSS config). Theme tokens are set with `@theme inline` in `app/globals.css`.
- Route prop types such as `LayoutProps<"/">` and `PageProps` are globals generated by Next, so you don't import them.
- Path alias: `@/*` maps to the repo root. Vitest resolves it via `resolve.tsconfigPaths` in `vitest.config.mts`.
