  lib/domain/citation-check.ts: validateReport(report, fetchedSources) returns
  { valid, errors }. A report has a bull section and a bear section, each a
  list of claims shaped { text, sourceIds }. fetchedSources is a list of { id,
  url }.

  Acceptance criteria:

  AC1: Every claim must cite at least one source, and every cited id must be in
  fetchedSources.
  AC2: A report must have at least one bull claim and one bear claim.
  AC3: Each error names the section, the claim number and the reason. A fully
  valid report returns valid: true with no errors.

  Do three red-green-refactor cycles, one per AC, in order. For each cycle:

  RED: write failing tests for that AC only, in
  lib/domain/citation-check.test.ts. Don’t touch the implementation. Run npm
  run test, confirm the new tests fail, then commit only the test file as
  “test(red): <short AC summary> (#3)”.
  GREEN: write the minimum code in lib/domain/citation-check.ts to make them
  pass. Don’t modify the tests. Run npm run test, confirm everything passes,
  then commit as “feat(green): <short AC summary> (#3)”.
  REFACTOR: if something is worth improving, refactor with the tests still
  green and commit as “refactor: <what changed> (#3)”. If nothing needs it,
  skip this step and say so.

  For AC1, cover a claim with no sources, a claim citing an unfetched id, a
  claim with one valid and one invalid id, and a claim with valid sources.
  After each commit, print one line: cycle, phase, test result. Don’t push.
